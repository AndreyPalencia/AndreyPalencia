## Proyecto destacado

**Sistema de Seguimiento al Aprendiz en Etapa Productiva (SENA)**
Aplicación full stack para gestionar fichas, aprendices, bitácoras, agendamiento, documentos y reportes, con roles de administrador, instructor and aprendiz. Proyecto de grado en equipo de 4 · versión estable.

- **Mi rol:** líder del equipo. Modelos y normalización con Sequelize, endpoints y middlewares, validación de datos, autenticación JWT con control de acceso por roles, integración frontend–backend con Axios, esquemas de validación con Zod y notificaciones en tiempo real con Socket.IO.
- **Stack:** Node.js, Express, Sequelize, MySQL, React, Material UI, FullCalendar, Socket.IO.
